Python para Nutrición

Python es el lenguaje más recomendado para estudiantes de nutrición por su sintaxis clara y amplia aplicabilidad en análisis de datos.

# Ejemplo: Cálculo de calorías diarias recomendadas def calcular_calorias(genero, peso, altura, edad, actividad): if genero.lower() == 'hombre': tmb = 88.36 + (13.4 * peso) + (4.8 * altura) - (5.7 * edad) else: tmb = 447.6 + (9.2 * peso) + (3.1 * altura) - (4.3 * edad) # Factor de actividad: sedentario=1.2, ligero=1.375, moderado=1.55, activo=1.725 return tmb * actividad # Ejemplo de uso calorias = calcular_calorias('mujer', 65, 165, 28, 1.375) print(f"Calorías diarias recomendadas: {calorias:.2f}")

JavaScript para Nutriólogos

JavaScript permite crear aplicaciones interactivas para cálculos nutricionales.

// Ejemplo: Calculadora de IMC interactiva function calcularIMC() { let peso = document.getElementById('peso').value; let altura = document.getElementById('altura').value; let imc = peso / (altura * altura); let resultado = ""; if (imc < 18.5) resultado = "Bajo peso"; else if (imc < 25) resultado = "Peso normal"; else if (imc < 30) resultado = "Sobrepeso"; else resultado = "Obesidad"; document.getElementById('resultado').innerHTML = `IMC: ${imc.toFixed(2)} - ${resultado}`; }
