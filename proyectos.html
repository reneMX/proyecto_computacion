Proyectos de Programación para Nutriólogos

¿Por qué realizar proyectos?

Los proyectos prácticos te permiten aplicar los conceptos de programación a situaciones reales de nutrición. Desarrollarás habilidades técnicas mientras creas herramientas útiles para tu futura carrera profesional.

Proyecto Destacado: Calculadora de IMC

Una aplicación web que calcula el Índice de Masa Corporal y proporciona recomendaciones personalizadas según los resultados.

// Código JavaScript para calcular IMC function calcularIMC() { let peso = document.getElementById('peso').value; let altura = document.getElementById('altura').value; if (peso > 0 && altura > 0) { let imc = peso / (altura * altura); let resultado = ""; if (imc < 18.5) resultado = "Bajo peso - Consulte con un nutricionista"; else if (imc < 25) resultado = "Peso normal - ¡Mantenga sus hábitos saludables!"; else if (imc < 30) resultado = "Sobrepeso - Recomendamos modificar su dieta"; else resultado = "Obesidad - Es importante consultar con un especialista"; document.getElementById('resultado').innerHTML = `IMC: ${imc.toFixed(2)} - ${resultado}`; } else { document.getElementById('resultado').innerHTML = "Por favor, ingrese valores válidos para peso y altura"; } }
