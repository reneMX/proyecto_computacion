Guías de Instalación

Cómo instalar Python

Sigue estos pasos para instalar Python en tu computadora:

  1. Visita python.org/downloads
  2. Descarga la última versión para tu sistema operativo
  3. Ejecuta el instalador y marca la opción "Add Python to PATH"
  4. Completa la instalación y verifica desde la terminal con python --version

Cómo instalar Git

Instalación paso a paso de Git:

  1. Visita git-scm.com/downloads
  2. Descarga la versión para tu sistema operativo
  3. Sigue las instrucciones del instalador con configuraciones predeterminadas
  4. Verifica la instalación con git --version en la terminal
